## 🚀 Featured Projects
### 🖼️ [Image Captioning — CNN vs Attention vs Transformer](https://github.com/BADIAMOHAMEDAYMANE/Image-Captioning-Project)
*From-scratch image captioning system in PyTorch, comparing three decoder architectures on the same pipeline.*
<p>
  <img src="https://img.shields.io/badge/PyTorch-EE4C2C?style=flat-square&logo=pytorch&logoColor=white"/>
  <img src="https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white"/>
  <img src="https://img.shields.io/badge/ResNet50-CNN%20Encoder-blue?style=flat-square"/>
  <img src="https://img.shields.io/badge/Attention-Bahdanau-blueviolet?style=flat-square"/>
  <img src="https://img.shields.io/badge/Transformer-Decoder-orange?style=flat-square"/>
  <img src="https://img.shields.io/badge/Dataset-Flickr8k-orange?style=flat-square"/>
</p>
- **Computer Vision:** Frozen ResNet50 encoder (transfer learning), global + 7×7 region feature extraction.
- **Deep Learning:** Three decoders built and benchmarked — LSTM baseline, Bahdanau soft attention, Transformer decoder (self- and cross-attention).
- **NLP:** Custom vocabulary pipeline, teacher forcing, greedy and beam search decoding.
- **Evaluation:** BLEU-1..4 scoring, automated model comparison table, training curves, error analysis (repetition/generic caption detection).
- **Interactive Demo:** Streamlit app — upload a photo, get a caption plus attention heatmaps showing where the model looks for each word.
- **Tools:** PyTorch, torchvision, Streamlit, Matplotlib, NumPy.
